# Soheil Mohajer — Modern CV Website

This is a **HTML + CSS** CV website for a frontend school assignment. The separate `cv.pdf` is the ATS-friendly resume. The site itself can use a more visual layout.

## Open locally

Double-click `index.html` to open it in Chrome. No npm, React or Live Server required.

## Publish to your existing GitHub repository

Update the **existing `Lexicon-CV` repository** with these files. Do not copy a `.git` directory from another project.

Upload/update: `index.html`, `style.css`, `cv.pdf`, `favicon.svg`, `images/profile.jpg`.

Important: after publishing, open the public URL and check that the photo, links and PDF download work. GitHub Pages needs the file name and letter casing to match exactly.

## Presentation highlights

- HTML5: semantic header, navigation, main, section, article and footer
- CSS3: Flexbox, Grid, responsive media queries and focus states
- Real functionality: CV download, email, phone, GitHub, Credly and LinkedIn links
- ATS-friendly PDF is deliberately separate from the visual CV website
