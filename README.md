# Modern CV Website – Soheil Mohajer
Frontend Individual Project 1 · Week 1 · Modern CV Website (Mandatory)
## Project Overview
This project is a modern, responsive CV website created as part of my frontend development training at Lexicon. The goal was to practise HTML5, CSS3 and user-interface design by presenting my professional background, skills, education and contact details in a clear and accessible format.
The website also offers a separate, ATS-friendly PDF resume for job applications.
## Project Goals
- Create a clear and professional personal CV website.
- Structure content using semantic HTML5.
- Design a responsive layout for desktop, tablet and mobile devices.
- Make navigation and important contact links easy to use.
- Practise CSS layout techniques, typography, colours and accessibility.
## Features
### Required project features
- Header / Introduction: Name, professional title and profile photograph.
- About Me: Professional profile and career goals.
- Skills: Technical knowledge, networking fundamentals and ongoing learning.
- Education: Academic qualifications and technical training.
- Contact: Location, email and phone information.
- Responsive design: Layout that adapts to different screen sizes.
### Additional features
- Work Experience: A timeline of previous roles and responsibilities.
- Download CV: A downloadable, ATS-friendly PDF resume.
- Professional links: GitHub, LinkedIn and Credly.
- Accessibility: Semantic sections, descriptive image text, keyboard focus styles and a skip link.
## Technologies Used
Technology	Purpose
HTML5	Semantic structure and website content
CSS3	Styling, colours, typography and spacing
CSS Grid	Main two-column CV layout
Flexbox	Alignment of navigation, buttons and content
Media Queries	Responsive desktop, tablet and mobile layouts
Git & GitHub	Version control and project sharing
GitHub Pages	Static website hosting


This CV website uses plain HTML and CSS; React, Bootstrap and Tailwind CSS are not required for this project.
## Project Structure
- index.html — Website structure and content.
- style.css — Styling, layout and responsive design.
- images/profile.jpg — Profile photo.
- cv.pdf — Downloadable ATS-friendly resume.
- favicon.svg — Website icon.
- README.md — Project documentation.
## Development Process
1. Plan: Selected the CV sections and organised the information.
2. Design: Chose a professional visual style, typography and colour palette.
3. Develop: Built the HTML structure and added custom CSS with Grid and Flexbox.
4. Test: Checked the layout in Chrome, including mobile view, and tested the CV download and links locally.
5. Deploy: Uploaded the project files to GitHub for publishing with GitHub Pages.
6. Explain: Prepared to demonstrate the website, code structure and learning process.
## Challenges and What I Learned
I practised organising longer CV content, keeping CSS consistent and adapting a two-column layout to smaller screens. I also learned how relative file paths work and why matching image filenames and letter casing matters when publishing a website.
Building this project strengthened my understanding of semantic HTML, CSS Grid, Flexbox, responsive design, GitHub and practical troubleshooting.
## Use of AI Tools
I used ChatGPT as a learning and development aid for explanations, design feedback, code review and troubleshooting. I worked through changes in VS Code, tested the website in the browser and practised understanding how the HTML and CSS work together.
Running the Website Locally
Open index.html in a web browser such as Chrome. No package installation or development server is needed for this HTML/CSS project.
